# Мини-приложение «Записать еду»

Страница поиска продуктов для Telegram-бота. Открывается кнопкой «🍽 Записать еду».
Человек находит продукты, выбирает порции и нажимает «Записать». Список «продукт + граммы»
уходит боту, а калории бот считает сам по своей базе.

Файлы:
- `index.html` — страница целиком: поиск, порции, «Недавнее», отправка боту;
- `data/base.json` — основная база продуктов (собирается из products.csv);
- `data/off.json` — товары из магазинов (собирается из off_ru.csv).

Обновить данные: на компьютере запустить `python build_webapp.py`, загрузить новую папку `data`
сюда и поменять `WEBAPP_VERSION` в keyboards.py.

## Источники данных и лицензии
- **USDA FoodData Central** (SR Legacy) — общественное достояние (CC0 1.0).
  Русские названия, веса порций и оценки для российских продуктов добавлены командой.
- **Open Food Facts** — © участники Open Food Facts, база по лицензии
  [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
  `data/off.json` — производная база: отобраны товары, продающиеся в России, почищены названия,
  убраны строки с ошибками, добавлены написания марок. Распространяется по той же лицензии ODbL 1.0.
